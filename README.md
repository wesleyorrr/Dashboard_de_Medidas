# ⏱️ Dashboard de Medida de Horas Trabalhadas - Power BI

Este projeto apresenta um **dashboard desenvolvido no Power BI** para acompanhamento das **horas trabalhadas por funcionário**, com visualizações claras, intuitivas e focadas em produtividade individual e total da equipe.

---

## ✨ Funcionalidades

- ⌛ **Total de Horas Trabalhadas por Funcionário**  
- 📊 **Gráfico de Porcentagem de Contribuição por Funcionário**  
- 🧮 **Estatísticas Detalhadas das Horas Trabalhadas**  
  - Média de horas por colaborador  
  - Comparação entre colaboradores  
  - Funcionários com mais e menos horas trabalhadas  

- 🔍 **Filtros interativos** por período ou por colaborador  
- 📈 Interface clara e ideal para uso por RH, líderes e gestores de equipe  

---

## 🛠️ Ferramentas Utilizadas

- **Power BI Desktop**  
- **Power Query** para tratamento de dados  
- **DAX (Data Analysis Expressions)**  
- Visualizações dinâmicas com gráficos de barras, pizza, KPI cards e tabelas

---

## 📁 Estrutura dos Dados

O dashboard foi construído com base nos seguintes campos:

- Nome do Funcionário  
- Data  
- Hora de Entrada  
- Hora de Saída  
- Total de Horas no Dia  
- Total Geral de Horas  
- Período de Apuração

## 🎯 Objetivo

- Monitorar a carga horária de cada colaborador  
- Identificar colaboradores com maior ou menor engajamento de tempo  
- Suporte à gestão de jornada de trabalho e folha de pagamento  
- Auxiliar no equilíbrio e redistribuição de tarefas de forma eficiente
